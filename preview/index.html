Install Fold & Tick

Take it to your watch.

Compatibility

Wear OS 5 or newer. Supports both 41 mm and 45 mm Google Pixel Watch 3 models.

View source on GitHub

Install over Wi-Fi

  1. On the watch, open Settings → System → About → Versions → Build number, then tap Build number seven times to enable Developer options.
  2. In Developer options, enable ADB debugging and Wireless debugging. Connect the watch and computer to the same Wi-Fi network.
  3. On the watch’s Wireless debugging screen, choose Pair new device. Run adb pair WATCH_IP:PAIRING_PORT and enter the pairing code shown on the watch. The pairing port and debug port are different.
  4. Connect with the separate debug port, then install the downloaded APK:
    adb connect WATCH_IP:DEBUG_PORT
    adb install -r Fold-and-Tick.apk
  5. On the watch, long-press the current face, choose Add new, then select Fold & Tick.

Previously installed a local debug build? Uninstall it once before switching to public releases because the signing key differs. This resets this face’s customization. Future public releases update with adb install -r.

Install on the watch, not the phone. You can turn wireless debugging off afterward.
